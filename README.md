# 羽毛标本三维展示系统

自然博物馆鸟类羽毛标本的浏览器端三维展示与编辑系统，面向研究员与公众观众。
纯 **TypeScript + 原生 WebGPU/WGSL** 实现，零运行时 3D 框架依赖。

## 功能页面

| 页面 | 能力 |
| --- | --- |
| 标本库 | 标本增删改查、复制、搜索；IndexedDB 持久化；JSON 导出/导入 |
| 羽毛编辑 | 鸟体头/身/翅/尾比例滑杆；7 个部位羽毛的数量、羽枝、形状、密度、颜色；结构色三参数；实时三维预览与截图 |
| 标本展示 | 单标本全屏轨道观察、自动旋转、FPS 监测、带参数截图 |
| 对比 | 两件标本并排，姿态双向同步联动；双视口自动限制 DPR 保帧率 |
| 设置 | 渲染质量三档、旋转灵敏度、FPS 开关、背景色、实例数量硬上限 |

## 核心技术设计

### 上万羽毛的性能方案（目标 ≥45fps）

- **4 个原型网格 + 实例化**：体羽/飞羽/尾羽/绒羽各一份几何，每根羽毛是一个 instance，
  整只鸟仅 4 次 `drawIndexed` 调用（加鸟体共 5 次 draw call）。
- **存储缓冲实例数据**：每实例 96 字节（模型矩阵 + 颜色 + 材质参数 + 稳定种子），
  1 万根约 0.96MB；按原型连续排布，翅膀实例独立区间支持局部更新。
- **真实羽枝几何**：羽轴 ribbon + 成对羽枝 ribbon（非贴图），原型按参数缓存复用，
  参数不变时零重建。
- **翅膀动画局部更新**：展开/收起只重写翅膀实例区间的缓冲，不重建整只鸟。
- **质量分级**：低/中/高档分别按 40%/70%/100% 缩放实例数与 DPR，配合实例硬上限防显存超限。

### 结构色（孔雀颈、鸽颈）

WGSL 内实现 **Airy 薄层干涉公式**：

- Fresnel 双偏振（s/p）反射系数 → 多光束干涉求和 → 9 波段可见光谱（420–660nm）
- 反射光谱经 **CIE 1931 XYZ** 积分 → 标准矩阵转线性 sRGB
- 输入仅为膜厚、折射率、观察角；**无任何随机项**，同一角度严格同色
- 默认预设：孔雀颈 310nm / n=1.6，鸽颈 380nm / n=1.55

### 各向异性高光

沿羽枝切线方向使用各向异性 GGX 分布（切线方向 α 小、副切线 α 大），
高光顺羽枝方向拉长；羽轴用独立标记获得更强、更窄的高光。

### 翅膀展开/收起与防穿插

- 肩关节坐标系：所有翅膀羽毛以相对肩关节的展开态锚点 + 方向定义
- 折叠/展开绕 `foldDir × spreadDir` 轴旋转，覆羽 `follow=0.4` 只部分跟随
- 折叠时沿体侧法线的逐层 `layer` 偏移消除共面穿插
- 初始变换与每帧动画走同一数学路径，展开-收起往返无累积漂移（脚本验证）

## 浏览器要求

Chrome / Edge 113+（桌面与安卓）、Safari 26+。不支持 WebGPU 时显示明确的降级提示页。

## 开发命令

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run validate   # 几何/排布/翅膀动画 + 薄层干涉物理验证（Node 端，无需 GPU）
npm run typecheck
```

## 验证覆盖（scripts/）

- `validate.ts`：原型网格合法性、实例排布与上限、单位四元数、同标本生成确定性、
  翅膀展开/收起可逆性、质量档缩放、极端参数上限保护、几何缓存复用
- `validate-film.ts`：同角度同色、角度变色、膜厚变色、能量合理、连续性（无闪烁）

## 目录结构

```
src/
  core/        数学库、轨道控制、颜色转换
  data/        默认预设（孔雀/鸽子/麻雀）、IndexedDB 与导入导出
  geometry/    羽毛原型网格、鸟体网格、实例排布与翅膀动画
  render/      WebGPU 设备/管线/实例缓冲、WGSL 着色器、视口与截图
  state/       全局状态（发布订阅 + 防抖持久化）
  ui/          路由、控件工厂、五个页面
scripts/       Node 端逻辑与物理验证
```
